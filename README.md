# Portfolio Volatility Calculator (C++ & Python)

A minimal beginner project demonstrating basic C++ algorithms, pointer memory management, and Python integration via `ctypes`.

## File Overview
- `calculator.cpp`: C++ function computing portfolio standard deviation across float arrays.
- `app.py`: Python script converting list data into C pointers and executing calculations.

## How to Run
1. Compile C++ binary: `g++ -O3 -shared -fPIC -o calculator.so calculator.cpp`
2. Run Python interface: `python3 app.py`
